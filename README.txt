FOTOMETRICA PRO — VERSÃO RECONSTRUÍDA DO CANVA

1. Para usar já no celular sem instalar: abra FotoMetrica_Canva_Utilizavel.html pelo Chrome, libere acesso a fotos/câmera.
2. Para gerar o APK Windows: instale Android Studio + Android SDK Platform 35.
3. Execute COMPILAR_APK_WINDOWS.bat (requer internet na primeira execução para Gradle e dependências).
4. O script grava FotoMetrica_PRO_Instalar.apk nesta pasta ao terminar com sucesso.
5. Instale o APK no Galaxy A07 autorizando a instalação de apps locais desta fonte.

OBS: ESTE PACOTE NÃO CONTÉM APK COMPILADO. Não temos SDK/Gradle no ambiente que criou o projeto.
Teste inicial realizado na versão HTML; câmera nativa e APK ainda precisam ser validados no aparelho.
Medição relativa a referência conhecida na mesma superfície/plano, não AR automática.
